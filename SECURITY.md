Security patches and dependency updates are applied to the default branch:

| Branch | Supported |
| :--- | :--- |

---

## Reporting a Vulnerability

If you discover a security vulnerability or credential leak within this profile repository:

1. **Do not create public GitHub issues or discussions.**
2. Report the vulnerability privately via **GitHub Security Advisories**:
   - Go to the **Security** tab of [imMohammedSahil/imMohammedSahil](https://github.com/imMohammedSahil/imMohammedSahil).
   - Click **Report a vulnerability**.
3. Or email the maintainer directly at: `mohammedsahil0003@gmail.com`.

### Response Timeline
- **Acknowledgment**: Within 48 hours
- **Resolution**: Target triage and remediation within 7 business days
